# Sousvite Widgetbook

Every `design_system` component with knobs, in the light, dark, and cooking themes and at 100% to 200% text. Published to https://tytaniumdev.github.io/Sousvite/ from `main`.

```sh
flutter run -d chrome   # in apps/widgetbook
```

To add a component: write its use cases in `lib/src/components/<name>.dart` and list it in `lib/src/directories.dart`.
